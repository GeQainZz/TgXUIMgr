# 按面板拆分日报用户用量

## 目标

每日流量日报保留总用量和各面板总用量，并将用户用量改为按面板分组展示。每个面板只展示该面板内用量最高的 10 个用户，不再生成跨面板合并的全局 Top 10。

## 方案

复用现有 `get_top_users(start_date, end_date, panel_name=...)` 查询能力，在日报生成时为每个面板单独查询 Top 10。新增纯文本格式化函数，将面板汇总和面板用户列表组合成稳定的 Markdown 文本，日报定时任务和 `/report` 手动命令继续共用同一生成函数。

## 输出规则

- 总用量、上传、下载保持现有格式。
- 各面板总用量保持逐行展示。
- 每个面板紧跟一个独立的“用户用量 Top 10”区块，按该面板的用量降序排列。
- 同名用户出现在不同面板时，分别归属于各自面板区块，不合并。
- 某面板没有用户用量时显示该面板区块，但不输出空用户排名。

## 验证

用单元测试验证两个面板不会混排、每个面板只保留 10 条用户记录，以及同名用户在不同面板中独立展示。部署后调用同一日报生成函数发送一条带测试标记的 Telegram 示例消息。
